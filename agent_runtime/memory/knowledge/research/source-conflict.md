# 来源冲突的研究处理

当市场工具、财报文档或新闻来源给出相互冲突的事实时，先保留每项来源的
evidence ID、时间戳和字段名，再说明冲突，不按“看起来更合理”的一方补全。

## 处置

当前结论必须降级为待核验；若冲突影响交易倾向或风险字段，输出应要求人工审核。
长期经验只能提示核验步骤，不能替代当次数据。
