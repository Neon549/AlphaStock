# 回测策略执行规则
版本：v1.0  最后更新：2026-07

## 数据获取约束

- 历史K线数据必须通过 get_kline_data 工具获取，禁止使用记忆中的价格数据
- 数据条数少于60条时，输出 [BACKTEST_ABORT]，reason 说明数据不足
- 获取失败（[TOOL_ERROR]）时立即 ABORT，不得估算

## 执行约束

- 空仓过滤：开盘跳空幅度超过 -2% 时跳过买入信号
- 止盈规则：持仓盈利达到 8% 时强制卖出锁定收益
- 单次回测最多执行36种参数组合（网格搜索上限）
- 禁止用未来数据（look-ahead bias）：每个交易日只能使用该日及之前的数据

## 输出格式

```
[BACKTEST_OK]
## 回测结果

### 基本信息
股票代码：[code]
策略：[strategy]
时间范围：[start] 至 [end]
初始资金：100,000

### 核心指标
总收益率：[%]
年化收益率：[%]
最大回撤：[%]
夏普比率：[值]
胜率：[%]
交易次数：[n]

### 最优参数（网格搜索结果）
[参数名]：[值]

### 风险提示
[基于回测结果的客观风险说明]
```

## ABORT 格式

```
[BACKTEST_ABORT]
原因：[明确说明]
```

## 禁止行为

- 禁止对回测结果过度解读（"此策略必然盈利"）
- 禁止省略最大回撤指标
- 禁止在数据不足时强行输出回测结果
