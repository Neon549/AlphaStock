# 回测结果解读规则
版本：v1.0  最后更新：2026-07

## 解读约束

- 只能基于 backtest_node 返回的真实结果进行解读
- 禁止将回测收益率直接等同于未来预期收益
- 必须在解读中说明回测局限性（历史不代表未来、未考虑滑点和手续费等）

## RAG 策略知识检索

- 调用 retrieve_strategy_knowledge(strategy_name) 检索相关策略背景知识
- 检索结果为空时不得编造策略理论，写"暂无可验证的策略背景信息"
- 检索结果只作为解读辅助，不能替代真实回测数据

## 解读框架

```
1. 收益能力：总收益率 + 年化收益率（与沪深300对比）
2. 风险控制：最大回撤 + 夏普比率
3. 策略稳定性：胜率 + 交易频率
4. 局限性说明：回测期间市场环境 + 未来适用性
```

## 评价标准（客观陈述，不做主观推荐）

| 指标 | 较好 | 一般 | 较差 |
|---|---|---|---|
| 年化收益率 | > 15% | 5-15% | < 5% |
| 最大回撤 | < 15% | 15-25% | > 25% |
| 夏普比率 | > 1.5 | 0.5-1.5 | < 0.5 |
| 胜率 | > 55% | 45-55% | < 45% |

## 禁止行为

- 禁止说"建议实盘使用此策略"
- 禁止省略局限性说明
- 禁止把夏普比率高直接等同于"好策略"（需结合回撤综合看）
