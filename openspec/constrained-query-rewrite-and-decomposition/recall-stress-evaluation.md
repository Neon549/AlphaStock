# Query Rewrite 信息缺口召回评测补充

状态：已实施；结论仅限候选诊断。

## 目标

对总集里最可能被平均指标掩盖的表达单独评测：简称、口语金融字段、上下文指代和缺失但可由已验证上下文补全的实体。错别字与复杂多来源问题不被伪装成已完成：前者仍需脱敏真实样本补充，后者继续走受约束任务分解。

## 约束与实现

- 仅使用本地股票字典、显式 ticker 和小型版本控制别名表；歧义后缀不解析。
- `context_stock_code` 只能补全没有实体的后续问法；用户文本中的显式 ticker 优先。
- 改写只追加检索词并输出审计原因；不覆盖原始 Query、数字、年份或代码。
- 复杂多来源、多跳问题不由改写器臆造结论，继续由受约束 LLM Decomposition 生成经 Schema/权限/依赖校验的任务图。

## 冻结候选 A/B

在 16 条合成“简称 + 口语”压力样本上，Recall@10 为 0.0625 → 0.3750，Precision@10 为 0.0063 → 0.0375，Citation hit 为 0.0625 → 0.4375，逐题 6 胜、0 负、10 平。在原 88 条通用候选变体上，Recall@10 与 Precision@10 均不变，MRR +0.0006、nDCG@10 +0.0005，1 胜、0 负、87 平。

压力集由固定 public-filing candidate 标签模板生成，未经过独立人工复核，也不是真实用户流量。因此它只能证明该实现对该类受控扰动有效，不能支持生产、线上泛化或简历效果声明。
